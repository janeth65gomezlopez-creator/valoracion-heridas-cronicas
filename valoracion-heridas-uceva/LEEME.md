# Valoración de heridas crónicas · UCEVA

Página web educativa (HTML, CSS y JavaScript, sin instalaciones) con información para la valoración de pacientes con heridas crónicas.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo `valoracion-heridas-uceva`) y sube **todo el contenido de esta carpeta** (index.html, css, js, assets, data, manifest.json).
2. En el repositorio: **Settings → Pages → Branch: main / (root) → Save**.
3. En 1–2 minutos tendrás la dirección pública, por ejemplo `https://janeth65gomezlopez-creator.github.io/valoracion-heridas-uceva/`.

## Panel Docente
- Abre la página, pulsa **Docente** e ingresa la contraseña. La contraseña inicial es **`uceva2025`**; cámbiala en *Panel Docente → Configuración y publicar*.
- Edita anuncios, programación, recursos, biblioteca, casos y eventos.
- Para que todos los estudiantes vean los cambios: *Configuración y publicar → Descargar content.json* y súbelo a la carpeta `data` del repositorio.
